SOLAR SIM - QUICK START
======================

1. Extract the entire ZIP. Do not run files from inside an archive.
2. Install Python 3.10 or newer from https://www.python.org/downloads/
   Python is required; it is not included in this download.
3. Open the extracted folder:

   Mac:     Double-click Start Solar Sim.command
   Linux:   Open a terminal here: sh "Start Solar Sim.sh"
   Windows: Double-click Start Solar Sim.bat (text mode)

If the Mac launcher will not open, open a terminal here and type:
   sh "Start Solar Sim.command"

Use macOS or Linux for the full-screen animated interface.
Make the terminal at least 64 columns by 22 rows.

Optional short commands (macOS/Linux):
   Run once in the extracted app folder: python3 install_commands.py
   Open a new terminal window, then type solar-sim or sol-sim.
   Both names work from any directory. No sudo is needed.
   Keep this folder in place; reinstall the commands if you move it.

Getting started from Terminal:
   sol-sim                 Open the app
   sol-sim --tutorial      Read the step-by-step walkthrough
   sol-sim --version       Show the installed version
   sol-sim -u              Install the newest stable GitHub release

Quit the app before updating; start it again with sol-sim after the update.
The updater checks the checksum and startup, preserves settings/caches/
exports, and backs up previous app files in update-backups/ inside the app.
Internet and write access to the app folder are required. --update also works.
Without short commands: python3 solar_sim.py --update (Windows: py -3 ...).
See GETTING_STARTED.txt, or /tutorial inside the app, for the full tutorial.

Try:
   /planet
   /orbit
   /day earth
   /mission list
   /mission Apollo 11 1 minute
   /setting
   /setting theme amber
   /live

Use /help for commands and /quit to exit.
In full-screen mode, Enter on empty input opens your selected screensaver.
Press Enter again to return to your previous view.
Arrows browse on empty input. /setting opens themes and screensavers directly.
Left/Right changes camera only in orbit view; Ctrl+P/N recalls command history.
Use /camera directly during missions. Left/Right or Ctrl+B/F edits typed input.
Use /camera system to restore automatic framing.
Read README.md for setup and README.txt for the full command guide.
